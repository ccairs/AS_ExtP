# AS_ExtP — After Effects AI 扩展平台

**简体中文** | [English](README.en.md) | [日本語](README.ja.md) | [Deutsch](README.de.md) | [한국어](README.ko.md) | [Français](README.fr.md) | [Русский](README.ru.md)

> 一个把 AI 接入 After Effects 的多模块扩展平台（CEP）。
>
> 版本：v1.0.4

AS_ExtP 是面向 After Effects 的 AI 扩展平台——一个 CEP 面板加两个原生 AE 插件（GLSL 效果宿主与 AE 热盒）。面板由多个模块构成：**Agent**（基于大语言模型的对话式操作）、**ComfyUI**（AI 图像 / 视频生成）、**素材库**（工程素材与预设管理），以及 **MCP / Skill / 记忆 / 模型管理**（能力扩展与配置）。

其中 **Agent 模块**是核心：用一句中文描述需求，AI 就能自主调用内置的 AE 自动化工具完成操作——创建合成、加图层、打关键帧、应用效果、渲染输出，全程无需手写代码；也支持让 AI 直接生成并校验执行 ExtendScript 脚本，甚至生成可在 AE 中实时运行的 GLSL / 线性 JS 像素效果。

此外，Agent 模块的**外接模式**能把整套 AE 操作能力以标准 **MCP Server** 形式供给外部 Agent 软件调用——在 Claude Code / Cursor 里直接说「帮我在 AE 里建个合成」，无需切换到扩展面板。接入方式见 [外接模式接入](#外接模式接入)。

## 核心功能

AS_ExtP 由 8 个功能模块组成，通过主面板的模块卡片或 3D 立方体导航进入。

![主面板：8 个功能模块卡片与底部状态栏](assets/readme/main-panel.png)

### 1. Agent 模块

核心模块，用自然语言与 AI 对话并驱动 AE。内置 **Script / Agent / Shader / 外接 / 团队** 五种工作模式（详见 [Agent 五种模式](#agent-五种模式)）：前四档为单 Agent 模式，第五档「团队」同时调度四条常驻 Agent 协作；「外接」模式可把工具集作为 MCP Server 供给外部 Agent 软件。支持多会话管理（会话切换器可按标题搜索）、工具权限三档（自动 / 平衡 / 保守）、任务计划跟踪、经验反思、推理强度调节与自定义 Agent 人格描述；支持目标自动续轮（顶栏目标条、`/goal` 命令，默认轮数上限 25、可配 1–500）；工具面可按视图收窄（Agent 模块设置 →「工具可见性」）。支持拖入图片、视频交给视觉模型分析画面，也支持 docx / xlsx / pdf 等文档解析为文本后再操作（Word 表格转为 Markdown 表格，内嵌图片提取到数据目录并在正文标出路径，重复 / 图标 / 超大图自动跳过，可按需用 `read_image` 查看；Excel 各 sheet 转为 CSV）；视频附件带悬停静音试播与全屏预览。

### 2. AE 工具

管理 AE 自动化工具的定义。工具按 **项目 / 合成 / 图层 / 动画 / 效果 / 渲染 / 工具**（外加用户自定义类别）分类组织。随包内置 11 个 AE 工具：项目面板与图层浏览、合成 / 图层 / 素材详情、渲染队列与跨合成搜索、环境与效果诊断、ExtendScript 执行、素材导入与替换、保存工程、渲染合成、文件夹列举、预览帧截图、图片分析；另含面板侧内建的撤销（`undoLastOperation`）与 AE API 文档查询（`queryAeApi`）。其余 AE 操作由 AI 用 `executeExtendScript` 现场写脚本完成。工具支持热重载，在面板内编辑后即时生效；也可由 AI 通过 `createAETool` 自行创建新工具——非只读的自建工具默认仅 Agent 可见，只读工具默认全局（脚本 / Shader 与外接模式均可见）；要让非只读工具也能被 [外接模式](#外接模式接入) 调用，创建时须显式声明含 `external-mcp` 的 scope；提供效果列表缓存功能，安装大量效果插件时可预生成缓存加速查询。

![AE 工具模块：工具列表与右侧工具编辑器](assets/readme/ae-tools.png)

### 3. ComfyUI

连接本地或云端 ComfyUI 服务生成 AI 图像和视频，结果可直接导入 AE 合成。支持**表单模式**出图与**画布模式**节点式可视化工作流编辑，可捕获 AE 当前帧作为输入，并支持批量生成与 WebSocket 实时进度显示。

![ComfyUI 画布模式：节点式工作流编辑](assets/readme/comfyui-canvas.png)

模板方面，内置 **13 套手调工作流**（文生图、图生图、GPT Image、Nano Banana、Seedream、海螺、Kling、HappyHorse、Seedance 等，含图生视频 / 参考图生视频 / 起止帧生成 / 全能参考等多种视频能力）。另接入 **ComfyUI 官方模板库（600+ 套）**：AI 可按需检索官方模板、自动展开子图并转换为可执行工作流；模型下拉项随服务端节点变化动态枚举，模板索引在本地磁盘缓存（断网可回退）。自定义工作流支持导入 ComfyUI 编辑器保存的 **UI 格式**与 **API 格式**（UI 格式自动转换；模板引用了本机未安装的**界面控制节点**——如 rgthree 的 Fast Groups Bypasser——时只跳过该开关节点并提示，不再整份拒绝），工作流目录固定为 `<数据目录>\comfyui\workflows`——把 .json 放进该目录，重开面板即自动加载。出于安全考虑，服务地址仅允许本机 / 内网。

### 4. 素材库

统一管理 AE 工程常用素材，以卡片堆叠方式分三个分区展示：

- **素材**：普通素材（图片 / 视频等）的虚拟引用，不复制实体文件
- **工程素材**：`.aep` 工程文件，可直接导入当前项目
- **预设**：`.ffx` 预设文件，可应用到选中图层或指定图层

支持批量导入并自动复现文件夹层级；视频素材提供可选分辨率（480p / 720p / 1080p / 原尺寸）的转码缓存，素材库模块设置里可关闭自动转码（仅控制素材库预览）。网格缩略图悬停静音试播；点击条目后右侧预览区自动静音循环播放（视频循环播放、序列帧逐帧循环播放），点击预览进入全屏；「清缓存」确认框显示可清理文件数与总大小（设置页显示当前占用）。单独的素材引用、工程素材与预设也可在快速执行栏中直接调用。

![素材库：卡片网格与右侧预览区](assets/readme/asset-library.png)

### 5. MCP 管理

管理外部 MCP（Model Context Protocol）服务器，扩展 AI 可用工具：支持 stdio、HTTP、SSE 三种传输，可启动 / 停止 / 监控服务器状态，自动发现工具并注册给 AI 调用。（注意方向相反：模块把外部 MCP 服务器接**进来**给面板内的 AI 用；[外接模式](#外接模式接入) 是把面板工具**送出去**给外部 Agent 用。）

### 6. Skill 管理

管理领域知识技能包，AI 在需要时按需加载获取专业指导。支持创建自定义技能，让 AI 遵循你的工作规范。

### 7. 记忆管理

AI 的持久化记忆系统，跨对话保留经验：记忆类型收敛为 **经验教训 / 项目记录 / 偏好设置** 三类，可指定作用域（Agent / Script / Shader 模式），支持 `[[wiki链接]]` 互链、全文搜索、多选批量删除；按模式维护的用户规则（Agent / Script / Shader 各一条）会自动注入 AI 的系统提示词，其余记忆由 AI 按需检索（`memory_search`）。

### 8. 模型管理

管理所有 AI 平台和模型配置：查看 / 添加 / 编辑 / 删除平台与模型、设置默认选择、自动发现模型、测试连接，并标记模型的视觉、工具调用、JSON 模式等能力。平台编辑器支持**自定义请求头**（每行 `名称: 值`）；内置预设可为平台声明**会话头**（如 OpenCode Go 的 `x-opencode-session`），请求时自动注入当前会话 ID，适配需要额外鉴权或路由头的第三方网关；内置 `opencode-go` 系列预设。

### 其他特性

- **外接授权指示器**：外接模式授权开启期间，面板四边常驻呼吸边光与置顶提示条，显示当前档位与对外工具数，外部 Agent 每次获准执行的工具调用会滚动显示工具名，便于确认当前是否处于对外放行状态
- **快速执行栏**：面板顶部全局快捷栏（固定覆盖层），无需进入模块即可执行脚本、应用预设、导入工程素材、引用素材，支持搜索过滤与批量操作
- **多语言界面**：可跟随 After Effects 界面语言，或手动切换简体中文 / English / 日本語 / Deutsch / 한국어 / Français / Русский
- **大肥鱼桌宠**：可启用 AI 桌面宠物（鲸鱼拟人角色，AI 生成），包含空闲漫步、点击弹跳、拖拽跟随、打瞌睡、说梦话等行为，支持对话、定时播报、主动回复与网页搜索
- **诊断日志**：全局设置中可**导出诊断包**（面板 / Bridge / 宿主 / 原生组件各进程日志 + 环境信息，统一脱敏，只保留最近 5 份）——反馈问题时附上该文件即可
- **主题与个性化**：多套预设主题与自定义配色**方案库**（方案可保存 / 应用 / 改名 / 删除，26 项可编辑色（20 项核心色 + 6 项语义状态色；`panel_theme` 工具读写全部 26 项），派生色自动计算）；面板内 Agent 可直接读改主题色与管理方案（工具 `panel_theme`，仅 Agent 模式可用、不对接外接模式）；背景叠加层、音效系统
- **3D 立方体导航**：可拖拽旋转、惯性滑动、面部聚焦转场
- **底部状态栏**：实时显示 Bridge 服务状态、AI 上下文用量、活跃模块与时钟

## Agent 五种模式

Agent 模块的模式开关有 5 档：前四档为单 Agent 模式——**Script / Agent / Shader / 外接**，覆盖从"纯代码"到"纯对话"再到"能力外供"的完整谱系；第 5 档**团队**让四条常驻 Agent 并行协作。通过顶栏模式开关切换：

### Script 模式

面向需要精确控制或分享复用的场景。AI 生成 ExtendScript 脚本代码，经语法校验与安全性审查后，可在预览区编辑再执行；生成的脚本可保存到本地，脚本树支持载入与项目管理。预览区提供「编辑 / 产物」双栏对照，遇到拦截或运行错误时按行高亮并给出结构化错误卡。

### Agent 模式

AI 自主调用全部 AE 自动化工具完成操作。例如直接描述「创建一个 1920×1080 的合成，加一个红色固态层，打 2 秒的透明度关键帧」。每次修改操作都会在 AE 撤销栈留下撤销组，`Ctrl+Z` 即可回滚；支持多轮对话保持上下文，支持拖入图片与文档再操作；可跟踪多步骤任务计划，并在对话中按权限策略确认危险操作；长任务可设为**会话级目标**（`/goal`），在轮数上限内自动续轮，流式瞬时失败也会自动续上。

### Shader 效果模式

在 AE 中**实时运行 GLSL / 线性 JS 像素效果**。AI 生成的 GLSL 先过编译校验并写入预览区；JS 效果先经静态危险代码预检、默认再过 LLM 二次审查，然后在面板侧沙箱中执行 `buildShader(params)` 编排逻辑、产出 GLSL 复用宿主渲染。定稿后可保存到效果库，由原生 [GLSL 效果宿主](#原生组件) 编译运行并热重载实时更新画面。内置参数（uniform）自动生成滑条 / 取色器控件，编译错误回传 LLM 自修复，支持效果库保存 / 加载 / 应用。

![Shader 效果模式：GLSL 预览、参数滑条与代码](assets/readme/shader-mode.png)

### 外接模式

把面板的工具集作为标准 **MCP Server** 对外供给，让外部 Agent 软件（Claude Code / Claude Desktop / Cursor / Trae / VS Code Copilot 等）直接操作你的 AE。切到「外接」档后，在管理台状态卡拨开「外部访问授权」总开关才对外放行；开关归用户显式控制，模式切换不会自动开启或关闭它。

面板在此模式下为六功能区同显布局：左列脚本树 + 效果库，中列 GLSL 预览图 + 管理台，右列脚本与 GLSL 代码预览；管理台含 **调用日志 / 审阅队列 / 设置** 三个页签，状态卡常驻顶行（总开关、Bridge 状态、对外工具数，右端是权限档位滚轮——与其他模式的「权限」滚轮同款，点一下循环切换）。外部 Agent 的每次调用都落在调用日志里，提交的脚本与效果另在审阅队列留下记录；经外部写入脚本库 / 效果库的文件，其条目在对应列表里带「外」徽标。

![外接模式：六功能区同显布局，管理台含调用日志 / 审阅队列 / 设置](assets/readme/external-mode.png)

接入配置见下一节。

### 团队模式

模式开关的第 5 档。开启后四条常驻 Agent 同时在线：**导演**（创意方案与计划书）、**AE 执行**（落地 AE 操作与出片）、**Shader 执行**（GLSL / JS 效果）、**美术执行**（图像 / 视频素材生成）。四条 Agent 各有独立的对话视图与任务计划；模型（含所属平台）与思考等级在 Agent 模块设置的「团队模式」段逐条配置——模型留空跟随全局默认，思考等级为必选档位（缺省 high），子 Agent 的并发上限（默认 3）与保活窗口（默认 10 分钟）也在该段设置。左抽屉提供「计划 / 团队任务」两个页签：计划是各 Agent 自己的待办，团队任务是四条共享的协作清单。各条 Agent 均可按需派生子 Agent（子 Agent 不能再派生）；各 Agent 通过发送消息工具互发消息，并通过团队工作区文件（计划书 `brief.md`、文字分镜 `storyboard.md` 等）交接产物。

![团队模式：四条常驻 Agent 并行协作](assets/readme/agent-team.png)

## 外接模式接入

### 前置条件（缺一不可）

1. **After Effects 已启动**，且 AS_ExtP 扩展面板已打开（本地 Bridge 进程随面板自动拉起，监听 `127.0.0.1:9877`，被占用时顺延至 9886）
2. **面板内已授权外部访问**：Agent 模块 → 模式开关拨到第四档「外接」，然后在管理台状态卡**手动拨开**「**外部访问授权**」总开关（**拨入模式不会自动授权**；取消授权时在同一开关关掉即可，关闭后所有**工具执行**返回 `EXTERNAL_MODE_OFF`，工具清单仍可列出）
3. **有 Node 运行时**（仅 stdio 传输需要）：扩展自带 `vendor\node\node.exe`（v22），**无需单独安装 Node.js**——Release 完整包已内置，源码克隆跑一次 `tools\check-env.bat` 会自动下载补齐

未授权时所有**工具执行**返回 `EXTERNAL_MODE_OFF`（工具清单仍可列出）；面板未打开但 Bridge 仍在时返回 `PANEL_OFFLINE`，Bridge 本身没起来（AE 未启动 / 面板从未打开）时返回 `BRIDGE_OFFLINE`。

### 传输方式选择

| 传输 | 接入方式 | 适用 | 说明 |
| --- | --- | --- | --- |
| **stdio**（推荐） | 客户端按配置拉起 `ext-mcp-server.js` | 全部客户端 | 客户端全权管理进程生命周期；支持确认交互 |
| **Streamable HTTP** | 客户端连 `http://127.0.0.1:<端口>/mcp` | Claude Code / Cursor 等支持 remote 接入的客户端 | 零新进程，Bridge 内嵌端点 |

HTTP 端口以 `/health` 探测为准（9877–9886 顺延）。先用 `curl http://127.0.0.1:9877/health`（失败则端口 +1 重试）确认端口，再填 URL。

### 客户端配置

AS_ExtP 的安装路径是固定的（`tools\install.bat` 与 `tools\deploy.bat` 都部署到此处）：

```
C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\AS_ExtP
```

任何支持 MCP 的客户端都只需加一条 **stdio 服务器**配置，内容只有两项：

- `command`：扩展自带的 Node `<扩展路径>\vendor\node\node.exe`（系统已装 Node ≥ 20.18 且在 PATH 时也可写 `node`）
- `args`：`<扩展路径>\client\shared\ext-mcp-server.js`；末尾可加 `--name <标识>`，用于确认弹窗的来源标注与 Bridge 日志，可省略（默认 `unknown`）——面板调用日志里显示的是自动生成的客户端 ID（形如 `ext-<pid>-<ts>`）

路径必须写绝对路径——MCP 客户端的工作目录不是扩展目录。各客户端之间只差配置文件位置与容器键名（如 `mcpServers` / `servers` / `mcp_servers`），字段就是上面两项。

### 权限档位与确认语义

面板外接状态卡右端的「权限」滚轮有两档（与 Agent / Shader 模式工具栏的权限滚轮同款控件，但外接只保留两档：点一下循环切换，鼠标悬停看语义说明）：

| 档位 | 行为 |
| --- | --- |
| **平衡**（默认） | 七组高危操作在**你所用 Agent 软件的界面内**弹确认（通过 MCP elicitation），其余直接执行 |
| **自动** | 全部外部调用直接执行，仅在调用日志留痕 |

需要确认的七组高危操作：创建 / 覆盖 AE 工具、记忆写入（四件）、素材文件夹删除、效果库删除、技能写面、脚本入库写入、MCP 服务器配置改动与运行控制（读操作不弹确认）。

如果客户端**不支持确认交互**（如 Claude Desktop、Cline，或走 HTTP 端点），这些高危操作会**直接拒绝**并返回 `CONFIRM_REQUIRED`，不会未经确认就执行。想放行请改用支持确认的客户端，或在面板把档位切到「自动」（等于明确授权全部放行）。

| 客户端 | 确认交互 |
| --- | --- |
| Claude Code / Cursor / VS Code Copilot | ✅ 在 Agent 软件内弹确认（60 秒无应答按拒绝处理） |
| Claude Desktop / Cline | ❌ 高危操作被拒（`CONFIRM_REQUIRED`） |
| HTTP 端点 | ❌ 同上（无 SSE 通道，无法下发确认） |

### 工具清单与动态变化

对外工具数默认 42 个（固定工具名单 46 件中记忆写 4 件默认关；不含网关与自定义工具，个别未注册的内建工具会被静默跳过）。可在设置页按 **12 个模块组**分别开关（AE 工程数据 / AE 元工具 / 自定义 AE 工具 / Agent 引擎 / 脚本模式 / Shader 模式 / 记忆 / ComfyUI 生成 / 素材库 / Skill / 外接任务 / 网关），组内还可逐工具开关。其中「网关」组默认关闭——它会把面板已接入的第三方 MCP 服务器一并对外供给，风险面最大，按需开启。支持 `tools/list_changed` 的客户端（Claude Code / VS Code）会在开关变化后自动刷新清单，Claude Desktop / Cursor 需重连客户端。

### 故障排查

| 症状 / 错误码 | 原因与处置 |
| --- | --- |
| `PANEL_OFFLINE` | Bridge 在运行但面板连接已断开——打开 AS_ExtP 面板 |
| `BRIDGE_OFFLINE` | Bridge 没起来（AE 未启动 / 面板从未打开）——先打开面板让宿主拉起 Bridge，或手动 `node client/shared/ae-bridge.js` |
| `EXTERNAL_MODE_OFF` | 「外部访问授权」总开关未开（切到外接档不代表已授权，需在状态卡手动拨开）；只拦工具执行，工具清单仍可列出 |
| `CONFIRM_REQUIRED` | 该操作需确认，但当前客户端不支持确认交互——换客户端或切「自动」档 |
| `CONFIRM_TIMEOUT` | 确认弹窗 60 秒内无应答，本次未执行 |
| `ACCESS_DENIED` | 工具被模块组 / per-tool 开关关停、不在对外白名单、工具抽屉未勾「外接」，或网关服务器未逐个开启 |
| AE 工具排队等待超时（…秒），本次调用未下发 | 面板 AE 引擎正被占用（面板内 Agent / 团队 lane / 另一次外接调用 / 正在跑的渲染或长脚本）。面板内 AE 调用共用一条 FIFO 队列（队列面板常开），排队超时保证本次未执行；等占用结束后重试 |
| `QUEUE_FULL` | 排队上限 32，稍后重试 |
| `RELAY_TIMEOUT` / `EXT_TIMEOUT` | 面板回包超时——相对闸门 90 秒（stdio 侧 100 秒），面板的 `ext_progress` 心跳会持续续期；调用可能仍在执行，先查调用日志再决定是否重试 |
| `EXT_TASK_PENDING` | 面板执行超过 30 分钟（固定上限，心跳不延长）——回包错误文本带 `taskId`，底层调用继续执行，用 `ext_task_get` 按 `taskId` 查询结果（面板重载后任务表清空） |
| HTTP 端点返回 503 | Bridge 未挂载该端点——确认 Bridge 由面板（或 `node client/shared/ae-bridge.js`）拉起 |
| 连不上 9877 | 端口被占用已顺延——逐个探测 `http://127.0.0.1:9877-9886/health` |

## 原生组件

除 CEP 面板外，项目还包含两个原生 AE 组件（C++，位于 `native/`）：

### GLSL 效果宿主（AS_Effect Host，`native/glsl-host/`）

一个通用的像素效果 `.aex` 宿主插件。效果逻辑存放在外部 `.glsl` 或由 JS 编排生成的 GLSL 文件中，改文件即热重载实时生效，无需为每个效果重新编译插件。支持 8bit / 16bit / 32bit（浮点）深度、GPU 渲染、按需 uniform 注册（浮点 / 向量参数自动映射为面板控件：滑条或取色器），编译失败不崩溃并写错误日志回传。这是 Shader 效果模式的运行时基础。

![GLSL 效果宿主在 AE 中实时渲染：左侧为 AE 合成与效果控件，右侧为扩展面板](assets/readme/glsl-host-in-ae.png)

三维与图像输入能力：

- **三维相机联动**：读取合成相机，把相机矩阵、位置、视场（`uCamFov`）注入内置 uniform，GLSL 里的透视与 AE 相机一致，可做真实的空间对齐
- **AE 灯光联动**：枚举合成灯光（类型 / 位置 / 朝向 / 颜色 × 强度 / 锥角衰减，最多 8 盏）注入 `uLight*` 系列 uniform，效果可对 AE 灯光实时反应
- **映射图层输入**：声明 `iChannel1/2/3` 即启用对应图层行（未声明时那三行常显但置灰——宿主 LAYER 行无法隐藏），可把其他图层作为纹理输入（`iChannel0` 为内置本图层）
- **参数槽位**：效果控件里只有一张自绘画布，「参数」组内按当前 shader 的 uniform 列表逐行绘制——标量是一根滑条，vec2 / vec3 的点控件按分量分行，vec4 与颜色语义向量渲染为取色器；行名与数值每帧从当前文件现取，复制图层、切换 shader、工程恢复后的首屏即正确。脚本与 AI 按宿主落盘的参数映射（`propertyIndex`）或参数 matchName 盘 ID 寻址；选中文件索引是隐藏参数 141（旧版 140 已后移）。量程与有效输入范围分开设置
- **效果库索引**：宿主导出权威序号，面板与宿主对效果库的认知自动同步，被选文件消失时透传而非静默换用别的 shader

![GLSL 效果宿主实测海洋效果：修改 .glsl 文件后画面实时热重载](assets/readme/glsl-host-in-ae-ocean.png)

### AE Hotbox（AS_Hotbox，`native/hotbox/`）

一个原生 AEGP 全局热盒插件，独立于 CEP 面板运行。在 AE 任意位置按下热键（默认 `Alt+Q`，可在面板全局设置内录制改键），鼠标处弹出浮窗：按住热键为**环形手势模式**（划向弧段即执行），点击中心圆进入**搜索模式**（长条搜索栏 + 线性结果 + 类型过滤）。搜索结果支持**拼音首字母与全拼**匹配（如 `gsmh` → 高斯模糊）。手势模式下浮窗已弹出时再按一次热键即关闭（开关语义）；搜索模式下该按键作为字符输入搜索框。松开热键后按任意字母可直接进搜索并预填该字符。

数据来自全部 AE 效果、`agent/scripts` 脚本与预设（素材库预设、AE 用户预设、AE 出厂预设三源合并去重）；插件作为 AEGP 与 AE 同进程运行，直接读取本地文件，不经 Bridge，也不要求扩展面板处于打开状态。合成相关的花瓣菜单提供**截图三动作**（复制到剪贴板，PNG 带透明通道 / 保存 PNG / 保存 JPG）。

#### 快速上手

1. 按 `Alt+Q`（或你录制的热键）→ 鼠标处弹出环形浮窗
2. 鼠标划向某个弧段 → 弧段高亮（金色描边）
3. 在弧段上松开鼠标 → 执行该弧段绑定的功能
4. 或者：点击中心圆 → 切到搜索模式 → 输入关键词 → `↑`/`↓` 选择 → `Enter` 执行

#### 手势模式（按住热键）

| 方位 | 弧段 | 说明 |
| --- | --- | --- |
| 正上 | 截图 | 悬停展开三瓣子菜单（PNG / 剪贴板 / JPG），不承载槽位绑定 |
| 右上 / 右下 / 左下 / 左上 | 4 个可绑定槽 | 可绑定固定功能（效果 / 脚本 / 预设），未绑定则为动态槽（回退为最近使用项）；搜索框为空时直接列出最近使用；设置面板的 4 个槽位行按 左上 / 左下 / 右上 / 右下 排列（见下节） |
| 正下 | 设置 | 点击进入设置面板，**松手在此不会执行**，需鼠标点击确认 |

- 松手判定：在弧段上（含该角度方向的环带外透明区）执行；在中心圆上不执行（防误触，需点击才进搜索）；在环内空洞与弧段间隙关窗且不执行。
- 浮窗已弹出时**再按一次热键 = 关闭**（开关语义，搜索模式除外）；松开热键后直接按任意字母即进搜索并预填该字符。
- **松手停留**（设置面板可切换，默认关）：开启后松手不执行也不关窗，改为鼠标点击选段——点击弧段执行、点击中心圆进搜索；关闭出口：`Esc`、再按热键、点击浮窗外部、点击环内空白处。设置写入 `<数据目录>\hotbox\config.json` 的 `releaseStay`，重启 AE 后保持。

#### 搜索模式（点击中心）

| 按键 / 动作 | 行为 |
| --- | --- |
| 搜索框为空 | 直接列出最近使用（按当前类型过滤，时间倒序），第一行默认选中；无记录时为输入提示 |
| 输入文字 | 实时模糊过滤（子序列匹配，不区分大小写） |
| 点击 `[全部 ▾]` | 过滤：全部 / 效果 / 脚本 / 预设 |
| `↑` / `↓`、滚轮 | 逐行移动选中（含首/末行环绕，滚轮与 `↑`/`↓` 同口径） |
| `Enter` / 单击列表项 | 执行选中项（FXConsole 风格：单击即应用） |
| `Esc` | 关闭热盒（从设置面板进入的绑定流程则返回设置面板） |

搜索模式**常驻不关闭**（热键可松开，双手打字），直到执行 / `Esc` / 点击外部。

**排序：最近使用优先**——命中结果里用过的排在前排：在「最近使用」列表（`recent.json`）中的项前移到最前，组内按最近使用顺序（时间倒序），其余项保持原顺序。输入变化后选中行回到第一行，所以「打完字直接回车」执行的就是最近用过的那条。搜索框为空时结果列表直接显示最近使用（按类型过滤、时间倒序，第一行默认选中，可直接 `Enter`/单击执行或绑定）；从设置面板进入绑定流程时同样列出最近使用（只绑定、不执行）。执行预设时少于 20 层一次完成、一次撤销全部，20 层及以上按块应用、撤销按块逐块进行。判定「用过」按同类型 + 同 `key`（效果 = matchName，脚本 / 预设 = 文件绝对路径），`key` 对不上时按同名兜底。列表容量 100 条（源码常量 `kRecentMax`），更早用过的项不再前移，也不再出现在空查询列表与手势环上；已失效的旧记录仍会列出，执行时提示失败，绑定会被拒绝。

#### 设置面板

4 个槽位行按手势环方位排列（左上 / 左下 / 右上 / 右下），逐槽绑定效果 / 脚本 / 预设；热键可录制改键；「松手执行」「松手停留」两个开关。配置存储在 `<数据目录>\hotbox\config.json`（数据目录默认 `%APPDATA%\Adobe\CEP\extensions\AS_ExtP`），最近使用列表在 `<数据目录>\hotbox\recent.json`。

> 构建、部署、排障与实现细节见 [DEVELOPMENT.md](docs/DEVELOPMENT.md)。

## 安装指南

### 环境要求

- **After Effects**：要求 **AE 2023（AEFT 23.0）及以上**（CEP 11 / CSXS.11，CEF 为 Chrome 88）；GLSL 效果宿主 / Hotbox 原生组件同样要求 AE 2023+。低于 AE 2023 的版本不受支持，`tools\install.bat` 会将其跳过并在汇总中提示。
- **Windows** 操作系统
- **Node.js ≥ 20.18**（仅源码克隆涉及）：本地 Bridge 与 stdio MCP 服务器的运行时。Release 完整包已内置 `vendor\node`；源码克隆跑一次 `tools\check-env.bat` 会自动下载补齐

### 取得文件（二选一）

| 方式 | 适用 | 包含 | 做法 |
| --- | --- | --- | --- |
| **Release 完整包**（推荐，**开箱即用**） | 普通用户 | 源码 + 预编译 `.aex` + 内置 Node 运行时与依赖 | 从 [Releases](../../releases/latest) 下载 zip 解压（**不需要装 Node、不需要 `npm ci`、不需要编译**），双击包内 `tools\install.bat` |
| **源码克隆** | 想读代码 / 自行编译 | 仅源码 | `git clone` → `npm ci` → 双击 `tools\check-env.bat`（补齐 `vendor\node`、ffmpeg 与 PlayerDebugMode）→ 双击 `tools\deploy.bat` 把文件铺到扩展目录 |

> 两个脚本分工：`install.bat` 是安装器（一条龙：探测 AE、下载 Node 与 ffmpeg、写 PlayerDebugMode、部署到扩展目录）；`deploy.bat` 是开发期的更新部署脚本（改了 `host` / `client` / `CSXS` 或 `vendor` 内容后，把最新文件重新铺到已安装的扩展目录；原生 `.aex` 不在扩展目录，仍由 `install.bat` 或手动复制到 AE 的 `Plug-ins`），不负责下载与注册表设置，首次使用前需先跑 `check-env.bat` 或 `install.bat` 备好 `vendor\`。

> 两种方式的分工：**Release 完整包开箱即用**（源码 + 预编译 `.aex` + 内置 Node 与依赖，解压双击 `install.bat` 即可，无需安装 Node、`npm ci` 或编译）；**源码仓库不含**这些预编译件与依赖（体积与分发限制，见 [素材与预编译件](#素材与预编译件)），需 `npm ci` / `check-env.bat` 补齐。自行编译原生组件需要 Visual Studio 与 Adobe AE SDK——SDK 依其许可不随仓库分发。`install.bat` 在源码目录内运行时，有 `deploy\Plug-ins\*.aex` 就自动部署，没有则跳过并提示。`deploy.bat` 要求 `vendor\` 目录已就位（由 `check-env.bat` / `install.bat` 创建），缺失时会提示先运行 `check-env.bat`；根 `node_modules` 会在部署时自动复制到 `vendor\node_modules`。

### CEP 扩展安装

1. 将整个项目文件夹放入 AE 扩展目录，**文件夹名必须是 `AS_ExtP`**（下面所有配置示例都按这个名字写）：
   ```
   C:\Program Files (x86)\Common Files\Adobe\CEP\extensions
   ```
   或使用 `tools\install.bat`（Release 包内 / 源码目录内均可运行）自动部署。

   > 注意：这个目录**不在 After Effects 的安装目录里**。AE 自己的安装目录（如 `E:\Adobe\Adobe After Effects 2023\`）下并没有 `CEP` 文件夹——AE 不携带自带面板，扩展统一从这个公共目录加载（部分其他 Adobe 应用安装目录下的 `<应用>\CEP\extensions` 只放它们自己的内置面板）。装好后扩展根目录为 `...\CEP\extensions\AS_ExtP`，[外接模式](#外接模式接入) 的 JSON 配置里用的就是这个路径。
2. 开启未签名扩展调试模式（必须）：
   - `Win+R` → 输入 `regedit` 打开注册表编辑器
   - 导航到 `HKEY_CURRENT_USER\SOFTWARE\Adobe\CSXS.11`（AE 2023 / 2024）或 `CSXS.12`（AE 2025+）——安装器对 AE 23/24 两个键都会写
   - 新建字符串值 `PlayerDebugMode`，数值数据设为 `1`
3. 允许 AE 脚本写入文件与访问网络：`编辑 → 首选项 → 脚本和表达式` 勾选对应选项
4. 重启 After Effects，通过菜单 `窗口 > 扩展 > AS_ExtP` 打开面板

> 本扩展不支持多个 AE 实例同时使用（bridge 为单实例；多开时请在其它 AE 中关闭面板）。

### 素材与预编译件

**Release 完整包开箱即用，源码仓库不是**：下列内容已内置在 Release 完整包中（解压后双击 `tools\install.bat` 即可用，无需安装 Node、`npm ci` 或编译）；**源码仓库不含**这些文件，克隆后需按「源码克隆」一行自行补齐。FFmpeg 两条路径均不含，由脚本下载：

| 内容 | 体积 | 缺失时的影响 / 替代 |
| --- | --- | --- |
| 预编译原生组件 `deploy/Plug-ins/*.aex` | ~2MB | Release 包已内置，`install.bat` 检测到即自动部署；源码克隆不含，缺失时 GLSL 效果宿主与 Hotbox 不可用，需自行编译 |
| Node 运行时 `vendor/node/` | ~84MB | Release 包已内置；源码克隆由 `tools\check-env.bat` 从 nodejs.org 下载固定版本并校验 SHA-256 |
| 依赖包 `vendor/node_modules/` | ~16MB | Release 包已内置；源码克隆跑 `npm ci`，`deploy.bat` / `install.bat` 会从根 `node_modules` 复制补齐 |
| FFmpeg `vendor/ffmpeg/` | ~200MB | **本项目不分发**：由 `tools\check-env.bat` / `tools\install.bat` 从上游固定版本下载并校验 SHA-256（许可与来源见 [THIRD-PARTY-NOTICES.md](docs/THIRD-PARTY-NOTICES.md)） |

> 桌宠美术 `client/features/deepseekPet/sprites/`（16 个 PNG + 1 个 WebM，约 110.5 MB）与 README 配图 `assets/readme/`（9 张 PNG，约 3 MB；画面中含桌宠形象）**均随源码树分发**，是本表之外仅有的非文本资产；桌宠形象的来源与权利状态见「免责声明」与 [THIRD-PARTY-NOTICES.md](docs/THIRD-PARTY-NOTICES.md) 第五节。

### 原生组件部署

用 `install.bat` 安装时会自动把 `.aex` 复制到各 AE 的 `Support Files\Plug-ins\`；手动安装则把 `deploy\Plug-ins\` 下的 `.aex` 复制过去，**完全退出并重启 AE** 后生效。

## 配置 AI 平台

## 安全注意事项

AS_ExtP 让 AI 自主操作 AE 并执行脚本，属于高权限自动化能力。使用时请注意：

- **危险能力默认关闭**：脚本的「运行系统指令 / 联网 / 读写文件 / 点击菜单」四类能力默认全部关闭（在「Agent 模块设置 → AST 门能力配置」中开启），「运行脚本免确认」同样默认关闭
- **脚本执行沙箱**：AI 生成的脚本默认在安全沙箱内执行，文件读写、系统命令调用等危险操作被拦截；执行前还会经过静态安全校验（AST 编译门），拦截已知逃逸手段
- **Shader / JS 效果预检**：JS 效果代码（`submit_js_effect` 与效果库 `.js` 写入）在写入 / 执行前强制静态危险代码预检，并默认经过 LLM 二次审查；GLSL 着色器提交时先过编译校验
- **外接模式授权**：授权由管理台「外部访问授权」总开关显式控制，模式切换不会自动开关它；授权期间面板有常驻边光与提示条，可随时关掉总开关中止外部访问。高危操作按档位确认，客户端不支持确认交互时**默认拒绝**而非放行；所有外部调用记录在调用日志中
- **文件操作路径保护**：所有文件操作限定在安全目录范围内，系统目录被自动拒绝，防止误删系统文件
- **使用建议**：运行脚本前做好备份；谨慎安装来路不明的 Skill 与 MCP 服务器（其内容会进入 AI 上下文）；仅连接可信的 ComfyUI 服务
